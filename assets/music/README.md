# Music Folder

Place your romantic background music here.

## How to use:
1. Add your music file to this folder (MP3, WAV, or OGG format recommended)
2. Rename it to `romantic.mp3` (or update the filename in `script.js` CONFIG.musicFile)
3. The music will automatically play with a smooth fade-in when "Yes" is clicked

## Recommended:
- Soft instrumental or piano romantic music
- Keep the file size reasonable (under 10MB for web)
- MP3 format works best for browser compatibility

## Note:
If no music file is found, the website will still work perfectly fine — music is optional.
