# Images Folder

Place your custom images here for the memory cards and gallery.

## How to use:
1. Add your images to this folder
2. Update the `src` attributes in `index.html` to point to your images
   - For memories: replace the `<img src="...">` URLs in the memories-grid section
   - For gallery: replace the `data-src` and `src` attributes in the gallery-grid section

## Recommended sizes:
- Memory cards: 400x300px or larger
- Gallery images: 800x800px or larger (square works best)
- Supported formats: JPG, PNG, WebP
